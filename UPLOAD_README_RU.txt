REPRONOVA — СТАТИЧЕСКАЯ ВЕРСИЯ ДЛЯ GITHUB PAGES

Готовая папка сайта, index.html — в корне архива. Извлечь содержимое архива в корень ветки публикации GitHub Pages (обычно main или gh-pages). Не загружать поверх непроверенных старых файлов без резервной копии.

Эта версия содержит облегчённые изображения WebP (исходное изображение сохранялось, если конвертация давала незначительную экономию). Семь подтверждённых публикаций имеют прямые внешние ссылки; остальные восемь логотипов визуальны, но не кликабельны. Архивный URL перенаправляет на страницу Media and Interviews.

ВАЖНО: GitHub Pages не запускает Python API. Формы и рассылка НЕ доставляют письма без отдельного HTTPS сервера. По просьбе заказчика настройка/приёмка почты отложена. Для реальной работы форм требуется отдельный этап настройки.

Состав 6 кейсов, 10 публикаций СМИ и профили соцсетей ещё нуждаются в подтверждении владельца.
